SUNSET BAY is an original top-down open-world crime game that runs entirely offline in the browser. Explore five districts of a hand-generated city, steal and drive cars with real momentum, dodge lane-following traffic and panicking pedestrians, climb a one-to-five-star wanted level while the Bay Patrol pursues you with cruisers, foot officers and roadblocks, and work through a five-mission story with taxi fares, a street race and a day/night cycle. Everything — art, map, characters, music and sound effects — is generated in code with no external assets.

## Run it
```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Use WASD to move, mouse to aim, left click to fire, Shift to sprint, E to enter or exit a vehicle, R to reload, M for the city map and ESC to pause. Add `?shot=cover`, `?shot=foot`, `?shot=drive` or `?shot=chase` for a deterministic screenshot scene.
